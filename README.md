♟️ Chess Game

📌 About the Project

Chess Game is a web-based chess project designed to provide a simple and enjoyable chess-playing experience. It features a chessboard interface where players can enjoy the classic game of chess.

🚀 Features

* Interactive chessboard
* Classic chess pieces
* Simple and user-friendly interface
* Responsive design
* Easy to play

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

├── index.html

├── script.js
└── README.md

💻 How to Run the Project

view site : https://chess-game-gamma-puce.vercel.app/

🎯 Project Goal

The main goal of this project is to practice web development skills using HTML, CSS, and JavaScript while creating an interactive chess game.
